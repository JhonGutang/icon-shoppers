# Existing Features

This document lists the currently implemented features for both Customers and Merchants in the Icon Shoppers platform.

## Customer Features

### Authentication & Profile
- **Unified Login/Register:** One account for all roles.
- **Profile Management:** Update personal details, contact number, and profile picture.
- **Address Book:** Save multiple shipping addresses and set a default one.

### Shopping Experience
- **Product Discovery:**
    - Browse all products with **Infinite Scrolling**.
    - Featured and Top-Selling product highlights.
    - Category-based filtering.
    - Real-time product search.
- **Product Details:** View product descriptions, images, prices, and stock levels.
- **Wishlist:** Save products to a personal wishlist for later.
- **Ratings & Reviews:** Rate products and shops after purchase.

### Real-time Communication
- **Live Chat:** Direct messaging between customers and merchants.
- **Messaging History**: Access past conversations with shops.
- **Unread Indicators**: Real-time count of new messages.

### Notification System
- **Real-time Alerts**: Instant push notifications for:
    - Order status updates.
    - New messages received.
    - New order placements (for merchants).
- **Notification Inbox**: A dedicated list to view and manage all system alerts.

### Order Management
- **Persistent Cart:** Add items to cart and have them saved across sessions.
- **Secure Checkout:** Simplified checkout process for the local region.
- **Regional Logistics:** Choose between pickup or local delivery.
- **Order History:** View past and current orders with detailed status tracking.
- **Order Cancellation:** Cancel orders that have not yet been processed.

---

## Merchant Features

### Shop Management
- **Shop Setup:** Create and customize your local shop profile.
- **Branding:** Upload shop logo and banner.
- **Analytics Dashboard:** Monitor total sales, order volume, and top-selling products.

### Product Management
- **Catalog Control:** Add, edit, and delete products.
- **Visibility Toggle:** Easily hide or show products from the public storefront.
- **Inventory Management:** Update stock levels and prices.
- **Featured Products:** Mark specific products to be featured on the homepage.

### Sales & Fulfillment
- **Order Processing:** Real-time notification of new orders via WebSockets.
- **Status Updates:** Manage the entire order lifecycle from approval to delivery.
- **Customer Insights:** View customer ratings and feedback for your shop and products.
- **Merchant Messaging**: Chat directly with customers to clarify order details.

---

## Administrative Features
- **User Moderation:** Manage user account statuses.
- **Shop Moderation:** Approve or suspend shops.
- **Category Management:** Define and organize product categories.
